# digitalizator

DIY náhrada CZUR skenera: Android telefón na stojane nad stolom, ovládanie z PC (klávesa alebo nožný pedál), ukladanie strán do PDF s OCR. Určené pre archivárky – plug and play, Windows 10/11.

Stav: plánovanie, žiadna implementácia.
